# 문제 6. 여행 상담 신청 폼 + 유효성 검사 (버그 수정형 JS) — 30분

## 시안 설명

**여행 상담 신청** 폼을 구현합니다. 제출 시 JS가 입력값을 검사해서 잘못된 필드에 빨간 테두리 + 에러 메시지를 표시합니다. (answer/index.html = 완성 시안)

```
┌──────────────────────────────┐
│  여행 상담 신청               │ ← 24px bold
│  전문 플래너가 연락드립니다   │ ← 15px #888
│                              │
│  이름                        │ ← label 14px #555
│  ┌────────────────────────┐  │
│  │                        │  │ ← input 높이 48px
│  └────────────────────────┘  │
│  이름을 입력해 주세요.       │ ← 에러 시: 13px 빨강, 테두리도 빨강
│                              │
│  이메일                      │
│  ┌────────────────────────┐  │
│  └────────────────────────┘  │
│                              │
│  ☐ 개인정보 수집·이용 동의   │
│                              │
│  [      상담 신청하기      ] │ ← 풀사이즈, 검정 배경
└──────────────────────────────┘
```

## 디자인 스펙

- 폼 박스: 너비 420px 가운데, 테두리 1px `#e5e5e5`, radius 16px, 패딩 40px 32px
- 제목 24px bold / 부제 15px `#888`, 제목 아래 8px
- 필드(`.form-field`): 필드 간 간격 20px
  - label: 14px `#555`, input과 8px 간격, **`for`↔`id` 연결 필수**
  - input: 전체 폭, 높이 48px, 테두리 1px `#ddd`, radius 8px, 좌우 패딩 14px
    - focus 시 테두리 `#111` (outline 대체)
  - 에러 메시지(`.error-msg`): 13px `#e53935`, input 아래 6px, 평소엔 빈 텍스트
  - **에러 상태(`.form-field.is-error`)**: input 테두리 `#e53935`
- 체크박스 줄: 체크박스 + label 가로 정렬, 14px
- 제출 버튼: 전체 폭, 높이 52px, 배경 `#111`, 흰 글자, radius 8px, hover `#333`

## 요구사항

1. `form`, `label for`, `input id`, `button type="submit"` 시맨틱/접근성 구조
2. JS가 요구하는 구조: `.inquiry-form`, `#userName`, `#userEmail`, `#agree`, 각 입력을 감싸는 `.form-field`, 그 안에 `.error-msg`
3. `start/form.js`에는 **버그(잘못됐거나 빠진 코드)가 3개** 있습니다. 찾아서 고치세요
4. 정상 동작 기준:
   - 이름이 비어 있으면 → 이름 필드에 에러 표시, 제출 안 됨
   - 이메일에 `@`가 없으면 → 이메일 필드에 에러 표시, 제출 안 됨
   - 동의 미체크 → alert, 제출 안 됨
   - 모두 통과 → "상담 신청이 접수되었습니다." alert
   - **어떤 경우에도 페이지가 새로고침되면 안 됨**
