안내문 핵심: **디자인 시안 → HTML/CSS 구현 + 제공된 JS를 구조에 연결/수정**

"페이지 하나 전체"가 아니라 **섹션 1~2개 + 인터랙션 1개**입니다.

### 빈출 유형 TOP 5
1. **탭 메뉴 + 콘텐츠 전환** (JS 제공 → 클래스명 맞춰 마크업) ★★★★★
2. **아코디언 / FAQ** (JS 제공 or 일부 수정) ★★★★★
3. **모달(레이어 팝업) 열기/닫기** ★★★★
4. **GNB + 드롭다운/hover 메뉴** ★★★★
5. **카드 리스트 그리드 레이아웃** (위 유형과 결합되어 출제) ★★★★★

이 폴더의 문제 1~3이 위 유형을 모두 커버합니다.

## 30분 시간 배분 (권장)

| 시간 | 할 일 |
|---|---|
| 0~3분 | 시안 분석: 섹션 나누기, 클래스명 계획, **제공된 JS부터 읽기** |
| 3~8분 | HTML 뼈대 전체 작성 (시맨틱 태그로) |
| 8~20분 | CSS 레이아웃 → 디테일 순서로 |
| 20~25분 | JS 연결 + 동작 확인 |
| 25~30분 | 시안 대조 검수, 들여쓰기/코드 정리 |

**핵심 요령: 제공된 JS를 먼저 읽으세요.**
JS가 `querySelectorAll('.tab-btn')`을 찾고 있다면, HTML 클래스명을 내 마음대로 짓는 순간 연결 작업이 두 배가 됩니다. JS가 기대하는 클래스명/구조에 맞춰 마크업하는 게 가장 빠릅니다.

## 시맨틱 마크업 체크리스트 (평가 항목 대비)

- `<header>` `<nav>` `<main>` `<section>` `<footer>` 사용
- 제목 계층: `h1` → `h2` → `h3` 순서 지키기 (건너뛰지 않기)
- 목록성 콘텐츠는 `<ul><li>`, 탭 버튼은 `<button>` (a나 div 아님)
- 이미지 `alt` 필수 (장식용이면 `alt=""`)
- 클릭 요소는 `<button type="button">` — div에 onclick 금지
- 폼이 나오면 `<label for>` ↔ `<input id>` 연결

## CSS에서 점수 갈리는 포인트

- 레이아웃: **flex 기본, 카드 그리드는 grid** (`repeat(3, 1fr)` + `gap`)
- 리셋 최소 3줄: `* { margin:0; padding:0; box-sizing:border-box }` + `li { list-style:none }` + `a { text-decoration:none; color:inherit }`
- 중앙 컨테이너: `.inner { max-width: 1200px; margin: 0 auto; }` 패턴
- 상태 클래스: `.is-active`, `.on` 처럼 일관되게
- hover / transition 시안에 있으면 반드시 구현 (0.3s ease 정도)
- 말줄임: 한 줄 `white-space:nowrap; overflow:hidden; text-overflow:ellipsis`

## 제공 JS 문제의 3가지 패턴

1. **연결형**: JS는 완성, 클래스명/구조만 맞추면 동작 → 문제 1
2. **빈칸형**: `classList.add( /* ??? */ )` 일부를 채움 → 문제 2
3. **수정형**: 버그 있는 코드(잘못된 선택자, 이벤트 등)를 고침 → 문제 3
