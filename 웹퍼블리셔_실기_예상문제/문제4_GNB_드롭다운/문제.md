# 문제 4. 헤더 GNB + 드롭다운 메뉴 (연결형 JS) — 30분

## 시안 설명

여행사 사이트의 **상단 고정 헤더**를 구현합니다. (answer/index.html = 완성 시안)

```
┌──────────────────────────────────────────────────┐
│ DREAM TOUR   해외여행  국내여행  골프  허니문  [로그인] │ ← 높이 80px, 상단 고정
└──────────────┬───────────────────────────────────┘
               │ (해외여행에 마우스 올리면)
        ┌──────┴─────┐
        │ 동남아      │  ← 드롭다운: 흰 배경, 그림자
        │ 유럽        │
        │ 일본        │
        │ 미주        │
        └────────────┘

  (스크롤을 내리면 헤더 아래에 그림자가 생김)
```

## 디자인 스펙

- 헤더: `position: fixed` 상단 고정, 전체 폭, 높이 80px, 흰 배경, 아래 테두리 1px `#eee`, z-index 넉넉히
  - 내부는 `.inner`(max-width 1200px) 안에서 로고 왼쪽 / GNB 가운데 / 로그인 버튼 오른쪽 (flex + space-between)
  - **스크롤 시(`is-scrolled`)**: 테두리 대신 그림자 `0 4px 12px rgba(0,0,0,.08)` (transition 0.3s)
- 로고: 텍스트 "DREAM TOUR", 20px bold (h1)
- GNB: 메뉴 4개(해외여행/국내여행/골프/허니문), 항목 간격 40px, 16px
  - hover 시 글자색 `#0066ff` + 아래 2px 밑줄(border 또는 가상요소)
- 드롭다운(서브메뉴): 각 메뉴 아래 `position: absolute`로 표시
  - 너비 160px, 흰 배경, 테두리 1px `#eee`, radius 8px, 그림자, 안쪽 패딩 8px 0
  - 항목: 상하 패딩 10px, 좌우 20px, hover 시 배경 `#f5f7ff`
  - 기본은 숨김, **`is-open` 클래스가 붙으면 표시**
- 로그인 버튼: 높이 36px, 좌우 패딩 20px, 테두리 1px `#111`, radius 18px
- 헤더 아래 본문: 아무 섹션이나 높이 1500px 정도로 채워서 스크롤 테스트 가능하게

## 요구사항

1. `header` / `nav` / `h1` / `ul li` 시맨틱 구조
2. **제공된 `start/gnb.js`는 수정 금지.** JS가 쓰는 클래스명·구조에 맞춰 마크업할 것
   - JS가 하는 일: ① 메뉴에 마우스 올리면 해당 항목에 `is-open` 부여 ② 스크롤 시 헤더에 `is-scrolled` 부여
3. 서브메뉴 표시/숨김과 그림자 전환은 **CSS로** 처리 (JS는 클래스만 토글)
4. 헤더가 fixed이므로 본문이 헤더에 가려지지 않게 처리할 것 (body padding-top 등)

## 채점 포인트

- [ ] 마우스 올리면 해당 메뉴의 서브메뉴만 열리는가
- [ ] 스크롤 시 그림자가 생기고, 맨 위로 오면 사라지는가
- [ ] 서브메뉴가 부모 메뉴 기준으로 정확히 아래에 붙는가 (relative/absolute)
- [ ] 본문 첫 콘텐츠가 헤더에 가려지지 않는가
