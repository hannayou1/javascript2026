# 문제 3. 이벤트 배너 + 모달 팝업 (버그 수정형 JS) — 30분

## 시안 설명

이벤트 배너 섹션과, 버튼 클릭 시 뜨는 **모달(레이어 팝업)**을 구현합니다. (answer/index.html = 완성 시안)

## 디자인 스펙

- 배너: 최대 너비 1200px 가운데, 패딩 60px, 둥근 모서리 16px,
  배경 `linear-gradient(135deg, #6a5af9, #f062c0)`, 글자 흰색, 가운데 정렬
  - 제목 32px bold / 부제 17px, 투명도 0.85 / 버튼: 흰 배경 · 글자 `#6a5af9` · 높이 48px · 좌우 패딩 32px · radius 24px
- dimmed: `position: fixed` 화면 전체, `rgba(0,0,0,.6)`, 기본은 숨김
- 모달: 화면 정중앙(포지셔닝 방법 자유), 너비 360px, 흰 배경, radius 12px, 패딩 32px
  - 닫기(✕) 버튼: 우측 상단, 20px
  - 쿠폰 박스: 점선 테두리 2px `#6a5af9`, 패딩 24px, 가운데 정렬, "20% OFF" 28px bold `#6a5af9`
  - 다운로드 버튼: 전체 너비, 높이 48px, 배경 `#111`, 흰 글자, radius 8px
- 동작: 열기 버튼 → 모달+dimmed 표시 / ✕ 또는 dimmed 클릭 → 닫힘 / 모달 떠 있는 동안 body 스크롤 잠금

## 요구사항

1. 시맨틱 마크업 + 모달에 `role="dialog"` 부여 (가산점 포인트)
2. `start/modal.js`에는 **버그가 3개** 있습니다. 찾아서 고치세요. (구조 변경 금지, 잘못된 부분만 수정)
3. 활성 클래스: `is-show` (모달 래퍼에 부여)
