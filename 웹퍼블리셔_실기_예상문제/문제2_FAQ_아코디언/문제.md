# 문제 2. FAQ 아코디언 (빈칸형 JS) — 30분

## 시안 설명

**자주 묻는 질문** 섹션을 구현합니다. (answer/index.html = 완성 시안)

```
┌──────────────────────────────────────┐
│  자주 묻는 질문                       │  ← 24px bold, 왼쪽 정렬
│                                      │
│  ┌────────────────────────────────┐  │
│  │ Q  배송은 얼마나 걸리나요?   ∨ │  │  ← 질문 행: Q뱃지 + 질문 + 화살표
│  ├────────────────────────────────┤  │
│  │ Q  교환/반품은 어떻게 하나요?∨ │  │
│  ├────────────────────────────────┤  │
│  │ Q  회원 등급 혜택이 궁금해요.∧ │  │  ← 열린 상태: 화살표 회전
│  │    답변 내용이 펼쳐집니다...   │  │  ← 답변: 회색 배경 #f8f8f8
│  ├────────────────────────────────┤  │
│  │ Q  비회원도 주문할 수 있나요?∨ │  │
│  └────────────────────────────────┘  │
└──────────────────────────────────────┘
```

## 디자인 스펙

- 컨테이너: 최대 너비 800px, 가운데, 상하 패딩 60px
- 아코디언 전체: 위쪽 테두리 2px `#111`, 각 항목 아래 테두리 1px `#e5e5e5`
- 질문 행(버튼): 전체 너비, 상하 패딩 20px, 좌우 패딩 16px, 왼쪽 정렬
  - "Q" 뱃지: 원형 28px, 배경 `#111`, 흰 글자, 질문과 12px 간격
  - 화살표(∨): 오른쪽 끝 배치, 열리면 180도 회전 (transition 0.3s)
  - hover 시 질문 글자색 `#0066ff`
- 답변 영역: 배경 `#f8f8f8`, 패딩 20px 24px, 글자 `#555`, 줄간격 1.6
- 동작: 한 번에 하나만 열림(다른 항목 자동 닫힘), 열린 항목 다시 클릭하면 닫힘

## 요구사항

1. FAQ 4개 이상, `ul > li` 구조, 질문은 반드시 `<button type="button">`
2. `start/accordion.js`의 **빈칸 (1)~(4)를 채워** 동작시킬 것 (빈칸 외 수정 금지)
3. 활성 클래스는 `is-open`, li에 부여

## 채점 포인트

- [ ] 하나 열면 다른 항목이 닫히는가
- [ ] 같은 항목 재클릭 시 닫히는가 (토글)
- [ ] 화살표 회전 transition이 있는가
- [ ] 질문이 button 태그인가 (키보드 접근성)
