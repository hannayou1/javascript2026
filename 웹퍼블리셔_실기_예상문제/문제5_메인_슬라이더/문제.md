# 문제 5. 메인 비주얼 슬라이더 (빈칸형 JS) — 30분

## 시안 설명

메인 상단의 **배너 슬라이더**를 구현합니다. 슬라이드 3장, 좌우 화살표, 하단 점(dot) 인디케이터. (answer/index.html = 완성 시안)

```
┌────────────────────────────────────────────┐
│                                            │
│  ◀   여름 휴가 특가                    ▶  │ ← 슬라이드: 높이 400px
│      동남아 리조트 최대 40% 할인           │    각 장마다 다른 배경색(그라데이션)
│      [ 자세히 보기 ]                       │
│                                            │
│                 ● ○ ○                      │ ← dot 인디케이터 (하단 중앙)
└────────────────────────────────────────────┘
```

## 디자인 스펙

- 슬라이더: 최대 너비 1200px 가운데, 높이 400px, radius 16px, **`overflow: hidden` 필수**
- 슬라이드 트랙: 슬라이드들을 **가로 일렬**로 배치 (flex), `transition: transform 0.4s`
  - JS가 `transform: translateX(-N%)`로 트랙을 밀어서 전환하는 방식
- 슬라이드(3장): 각각 슬라이더 폭 100% (`flex: 0 0 100%`), 내용 세로 중앙 정렬
  - 배경: 1장 `linear-gradient(135deg,#36d1dc,#5b86e5)` / 2장 `(135deg,#f7971e,#ffd200)` / 3장 `(135deg,#834d9b,#d04ed6)`
  - 제목 36px bold 흰색, 부제 18px 흰색(투명도 0.9), "자세히 보기" 버튼: 흰 배경, radius 22px, 높이 44px
- 화살표 버튼: 좌우 가장자리 세로 중앙, 원형 44px, 반투명 흰 배경 `rgba(255,255,255,.7)`, hover 시 불투명
- dot: 하단 중앙, 10px 원형, 기본 `rgba(255,255,255,.5)`, 활성(`is-active`)은 흰색 + 폭 24px(알약 모양, transition)

## 요구사항

1. `start/slider.js`의 **빈칸 (1)~(4)를 채워** 동작시킬 것 (빈칸 외 수정 금지)
2. JS가 요구하는 구조: `.slider > .slide-track > .slide`, 버튼 `.btn-prev` `.btn-next`, 인디케이터 `.dot`
3. 마지막 슬라이드에서 다음 → 첫 슬라이드로, 첫 슬라이드에서 이전 → 마지막으로 순환
4. dot 클릭 시 해당 슬라이드로 바로 이동

## 채점 포인트

- [ ] 좌우 버튼·dot 모두 동작하고 순환되는가
- [ ] 전환이 스르륵(transform transition) 움직이는가 — display 전환이면 감점 포인트
- [ ] overflow: hidden으로 옆 슬라이드가 안 보이는가
- [ ] 화살표·dot이 슬라이드 위에 겹쳐 떠 있는가 (position absolute)
