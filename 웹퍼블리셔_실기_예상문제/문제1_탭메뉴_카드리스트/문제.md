# 문제 1. 탭 메뉴 + 상품 카드 리스트 (연결형 JS) — 30분

## 시안 설명

**BEST ITEM 섹션** 하나를 구현합니다. (answer/index.html을 열면 완성 시안을 볼 수 있음)

```
┌──────────────────────────────────────────────┐
│                BEST ITEM                     │  ← 섹션 제목, 가운데, 28px bold
│        이번 주 가장 사랑받은 상품            │  ← 부제, #888, 15px
│                                              │
│   [ 전체 ] [ 아우터 ] [ 상의 ] [ 하의 ]     │  ← 탭, 가운데 정렬
│   ───────                                    │     활성 탭: 검정 배경 + 흰 글자
│                                              │
│  ┌──────┐  ┌──────┐  ┌──────┐  ┌──────┐      │
│  │ IMG  │  │ IMG  │  │ IMG  │  │ IMG  │      │  ← 4열 그리드, gap 20px
│  ├──────┤  ├──────┤  ├──────┤  ├──────┤      │
│  │상품명 │  │상품명 │  │상품명 │  │상품명 │      │  ← 16px, 한 줄 말줄임
│  │가격   │  │가격   │  │가격   │  │가격   │      │  ← 15px bold
│  └──────┘  └──────┘  └──────┘  └──────┘      │
└──────────────────────────────────────────────┘
```

## 디자인 스펙

- 컨테이너: 최대 너비 1200px, 가운데 정렬, 섹션 상하 패딩 60px
- 탭 버튼: 높이 40px, 좌우 패딩 24px, 테두리 1px `#ddd`, 둥근 모서리 20px, 버튼 간격 8px
  - 활성(`is-active`): 배경 `#111`, 글자 `#fff`, 테두리 `#111`
  - hover 시 테두리 `#111` (transition 0.3s)
- 카드: 4열 그리드, gap 20px
  - 이미지 영역: 배경 `#f0f0f0`, 높이 240px, 둥근 모서리 8px (이미지 대신 배경색 박스 허용)
  - 카드 hover 시 이미지 영역이 살짝 어두워짐(`#e2e2e2`)
  - 상품명: `#333`, 한 줄 말줄임 처리
  - 가격: bold, 상품명과 6px 간격

## 요구사항

1. 시맨틱 마크업으로 HTML 작성 (`section`, 제목 태그, 탭은 `button`)
2. **제공된 `start/tab.js`는 수정 금지.** JS가 요구하는 클래스명·구조에 맞춰 마크업할 것
3. 탭 4개(전체/아우터/상의/하의), 각 탭마다 카드 4개짜리 패널 (내용 텍스트는 자유)
4. 첫 탭이 기본 활성 상태

## 채점 포인트 (혼자 검수할 때)

- [ ] 탭 클릭 시 패널 전환이 동작하는가 (JS 무수정)
- [ ] 탭이 `button type="button"`인가
- [ ] 카드 리스트가 `ul > li` 구조인가
- [ ] grid + gap으로 레이아웃했는가
- [ ] 말줄임, hover, transition 구현했는가
